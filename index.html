Research

Soil moisture data fusion and hybrid nowcasting

Sponsored research for Aperture Space, Inc.

In a benchmark on 340 U.S. stations, my model’s median error was 0.0421 m³/m³. SMAP L4 v007 scored 0.0540 on the same observations, so my error was 22% lower. Both used the same de-biasing and station-held-out cross-validation.

How big is the error, compared with real sensors?

What went into the dataset

3.06M station-days of ground observations from 1,599 stations in 56 networks (ISMN).
ERA5-Land and CHIRPS weather, plus IMERG and PRISM precipitation.
SoilGrids soil properties, SRTM terrain, and ESA WorldCover land cover.
1.44M Sentinel-1 radar acquisitions, Sentinel-2 optical indices, and MODIS land-surface temperature.
  • Method. A gradient-boosted model estimates today’s moisture, and temporal residual corrections adjust it. A 90-day weather and satellite CNN extension is in multi-seed evaluation.
  • Skill metric. 1 − A/B compares model error (A) with a seasonal-average baseline (B) on the same observations. It shows what the model learns beyond the seasonal cycle.
  • Careful joins. Dates are corrected to local time, only past weather is used, and every satellite acquisition is kept.

Adaptive time-series tokenization and forecasting

Research in progress.

Extends Chronos so its token boundaries adapt, guided by per-bucket error and uncertainty, while the vocabulary size stays fixed.

  • Training. Embeddings are remapped by token count and optimizer state is reset whenever boundaries change, including the shared input and output embeddings.
  • Evaluation. Chronos and PatchTST run with held-out series tails and rolling-origin backtests, scored by MASE and WQL. Tests check vocabulary size, remapping, and that training and evaluation targets never overlap.

  • Batch jobs leave the web request. Redis-brokered Celery workers run them and PostgreSQL keeps the job state. A failed callback is retried on its own, so the translation never runs twice.
  • Two engines. OPUS-MT models and one shared 600M-parameter NLLB model. Models load on demand, the least recently used one is evicted, and GPU runs use fp16 with warmup.
  • Less repeated work, safer access. Sentence caches are shared across all paths. Each API key has quotas and sliding-window rate limits.

An interactive 36-country map of each country’s top news and internet culture, explained for outsiders by a language model.

How the weekly refresh works

Google News RSS, Reddit, and the YouTube Data API. A global rate-limit throttle, read-only Reddit OAuth in CI, and per-source fallback keep ingestion running.
Rule-based filters handle recall and coarse ranking by dropping, penalizing, or boosting items. That keeps the ranking easy to debug.
The language model does only two jobs: the final selection and the cross-cultural explanation.
GitHub Actions refreshes static JSON every week. Cost stays near $6 a year, whatever the traffic.
A 36-country map in vanilla JavaScript and SVG over GeoJSON, with no backend or database. Open the live demo.
  • Two pipelines. News and internet culture are separated, because one trending feed was dominated by news. Hard-exclusion rules can be audited.
  • No model calls in the browser. Explanations are generated in batch and served as scheduled static JSON. Failed sources have fallbacks, and the regression tests need no network.
